# 2-minute demo script

## 0:00–0:20 — Problem

Launching a token is easy; choosing liquidity parameters that fit the asset is not.

## 0:20–0:45 — CurvePilot

Describe the asset and select an asset profile.

## 0:45–1:10 — Curve recipe

Show the generated curve profile, fee configuration and graduation threshold.

## 1:10–1:35 — Meteora

Show the actual DBC launch transaction and live pool.

## 1:35–1:50 — Graduation

Show graduation state and post-graduation liquidity destination.

## 1:50–2:00 — Why it matters

CurvePilot turns liquidity configuration into a reusable programmable primitive.
